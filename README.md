<p align="center">
  <strong>A cleaner way to explore the web.</strong>
</p>Vex Proxy is a modern, aesthetic web browsing project featuring a cinematic automotive background, minimalist interface, and a custom search experience.

Features

- Modern glassmorphism interface
- Responsive mobile and desktop layouts
- Automotive video background
- Search bar with URL detection
- Quick-access website shortcuts
- Dark aesthetic design
- Cloudflare-powered backend (in development)
